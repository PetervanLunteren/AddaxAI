# Frequently asked questions

Short answers, with a link to the full explanation. Select a question to open it.

<FaqExpandAll />

## Getting started

<FaqItem id="which-workflow-should-i-use" q="Which workflow should I use?">

A project if you want AddaxAI to make rates, charts and maps. A folder run if you do that part yourself, in Timelapse or R for example. Not sure? Start with a folder run. See [choose a workflow](../start-here/choose-a-workflow.mdx).

</FaqItem>

<FaqItem id="is-it-free" q="Is it free?">

Yes. AddaxAI is open source under the MIT licence, also for commercial work.

The models have their own licences, and many are non-commercial. Check the licence before you use a model commercially. Every licence is listed in the [model zoo](../reference/model-zoo.mdx).

</FaqItem>

<FaqItem id="why-do-some-models-ask-me-to-accept-a-licence" q="Why do some models ask me to accept a licence first?">

Six models run on a package called ultralytics, which has its own licence (AGPL-3.0): SharkTrack, MegaDetector v1000 Larch and Sorrel, and the Namibia (Skeleton Coast), New Zealand (invasives a) and Turkmenistan species models.

You can use them on your own data and use the results for any work. You can't build them into an app or service you give or sell to others, unless you share its source code under the same licence. The full licence is on the [Ultralytics website](https://www.ultralytics.com/license).

</FaqItem>

<FaqItem id="my-computer-warns-that-the-app-is-unsafe-or-blocks-it" q="My computer warns that the app is unsafe, or blocks it">

That warning is normal for a new app. On Windows click More info, then Run anyway. On macOS click Open, or allow it under System Settings > Privacy & Security. If a work computer blocks it completely, see [install on locked-down computers](locked-down-computers.mdx).

</FaqItem>

<FaqItem id="setup-downloads-fail-or-never-finish" q="Setup downloads fail or never finish">

The first launch downloads the models and the software they run in. See [install in mainland China](install-in-china.mdx) for China, [install on locked-down computers](locked-down-computers.mdx) for a work network, and [antivirus on your own computer](locked-down-computers.mdx#antivirus-on-your-own-computer) if your antivirus stops it.

</FaqItem>

<FaqItem id="how-do-i-start-over-with-a-clean-install" q="How do I start over with a clean install?">

None of these touch your photos, videos or exports.

- Setup failed: open Help > Reset application and type RESET. Setup runs again on the next start. Your projects stay, unless you tick the box to remove them too.
- Remove the app: uninstall it as described under [installation](../start-here/install.mdx), and say yes to deleting your data.
- Remove version 6: open Help > Remove old AddaxAI. Version 7 is not touched.

</FaqItem>

## Privacy and data

<FaqItem id="does-my-data-get-uploaded-anywhere" q="Does my data get uploaded anywhere?">

No. Everything runs on your computer, and your photos and videos never leave it.

The app goes online only to fetch models, check for a new version, load map backgrounds and look up a new label name on GBIF.

</FaqItem>

<FaqItem id="do-i-need-an-internet-connection" q="Do I need an internet connection?">

Only the first time you use a model, to download it. After that, analysis runs offline.

With limited internet, run one small analysis with the models you plan to use while you still have a good connection.

</FaqItem>

<FaqItem id="does-addaxai-change-my-photos" q="Does AddaxAI change my photos?">

No. It never writes to your photos and videos. It writes a hidden `.addaxai` folder next to them and the outputs you ask for, which are always copies. See [where your files live](../reference/file-locations.md).

</FaqItem>

## Requirements

<FaqItem id="do-i-need-a-gpu" q="Do I need a GPU?">

No. It's faster with an NVIDIA GPU or Apple Silicon, but it runs on any computer.

</FaqItem>

<FaqItem id="how-long-does-an-analysis-take" q="How long does an analysis take?">

It depends on your hardware and how many files you have. A GPU makes it many times faster. For numbers, see the [MegaDetector benchmark timings](https://github.com/agentmorris/MegaDetector/blob/main/megadetector.md#benchmark-timings). Videos are slower, and a lower frame rate in the advanced settings speeds them up.

</FaqItem>

<FaqItem id="it-does-not-use-my-gpu-what-can-i-do" q="It does not use my GPU. What can I do?">

Install the latest NVIDIA driver; an RTX 50-series card needs version 555 or newer. Some old cards can't be used at all, and AddaxAI then runs on the processor, just slower. See [installation](../start-here/install.mdx).

</FaqItem>

## Understanding the results

<FaqItem id="what-is-the-difference-between-a-detection-and-an-observation" q="What is the difference between a detection and an observation?">

A detection is one box. An observation is one species in one event, with a count. See [detections, events and observations](../understanding/detections-events-observations.mdx).

</FaqItem>

<FaqItem id="why-are-labels-and-counts-not-the-same-thing" q="Why are labels and counts not the same thing?">

Labels say which species, counts say how many. They're checked on different pages, so check the labels first, then [confirm the counts](../guides/confirm-counts.mdx).

</FaqItem>

<FaqItem id="can-i-confirm-counts-in-a-folder-run" q="Can I confirm counts in a folder run?">

Yes, in step 3. It's optional: skip it and the AI's counts go into the counts table. See [confirm the counts](../guides/confirm-counts.mdx).

</FaqItem>

<FaqItem id="some-photos-have-no-date-what-happens-to-them" q="Some photos have no date. What happens to them?">

They're analysed and count in your species totals, but they drop out of trap nights and the charts over time. You can give them a date from the filename or the file dates. See [dates, times and timezones](../understanding/capture-times.md).

</FaqItem>

<FaqItem id="what-is-the-difference-between-animal-and-animalia" q="What is the difference between Animal and Animalia?">

Both mean an animal nobody could name. "Animal" means the species model never looked at the box. "Animalia" means it looked, but was not sure at any level below kingdom. See [how labels get cleaned up](../understanding/label-cleanup.md).

</FaqItem>

<FaqItem id="what-does-each-column-in-the-csv-mean" q="What does each column in the CSV mean?">

Every column of every table is described in [exports](../reference/exports.md).

</FaqItem>

## Using AddaxAI

<FaqItem id="can-i-correct-the-ai" q="Can I correct the AI?">

Yes, and your corrections always win. See [confidence and verification](../understanding/confidence-and-verification.md).

</FaqItem>

<FaqItem id="can-i-analyse-a-single-video-or-a-few-files" q="Can I analyse a single video or a few files?">

Not directly. AddaxAI analyses a whole folder. Put the files in a folder of their own and pick that folder.

</FaqItem>

<FaqItem id="can-a-project-sort-my-photos-into-species-folders" q="Where are the photos with animals? Can I get them sorted into species folders?">

Yes, as copies. In a folder run, pick species folders in the Save step. In a project, use Image copies on the Export page. See [exports](../reference/exports.md#image-copies).

</FaqItem>

<FaqItem id="which-species-can-it-recognise" q="Which species can it recognise?">

It depends on the model. The [model zoo](../reference/model-zoo.mdx) lists the species of every model, and you can search it by name.

</FaqItem>

<FaqItem id="can-i-add-a-species-the-model-does-not-know" q="Can I add a species the model does not know?">

Yes, as a new label in the relabel picker. The model won't learn it, so you assign it by hand. See [species names and taxonomy](../understanding/species-names.md).

</FaqItem>

<FaqItem id="why-do-some-images-have-no-boxes-during-review" q="Why do some photos have no boxes during review?">

Their boxes score below your threshold, so they're hidden. Lower the threshold to see them. See [confidence and verification](../understanding/confidence-and-verification.md).

</FaqItem>

<FaqItem id="what-is-the-difference-between-the-detection-models" q="What is the difference between the detection models?">

MegaDetector v5a is the default and the most tested, so keep it unless you have a reason. The v1000 models are faster but less accurate. See the [model zoo](../reference/model-zoo.mdx).

</FaqItem>

<FaqItem id="can-several-people-work-on-the-same-project" q="Can several people work on the same project?">

Not at the same time, but you can split the checking by deployment. See [split the checking over a team](../guides/work-as-a-team.mdx#split-the-checking-over-a-team).

</FaqItem>

<FaqItem id="can-i-add-many-sites-or-deployments-at-once" q="Can I add many sites or deployments at once?">

Yes, from a CSV file. Import the sites first. See [build a project](../guides/build-a-project.mdx#import-from-a-spreadsheet).

</FaqItem>

<FaqItem id="can-i-move-my-work-to-another-computer" q="Can I move my work to another computer?">

Yes. See [moving to another computer](../reference/file-locations.md#moving-to-another-computer).

</FaqItem>

<FaqItem id="can-i-undo-a-big-mistake" q="Can I undo a big mistake?">

Often yes. AddaxAI copies your database every day, and you can go back to a copy. See [back up and restore](./back-up-and-restore.md).

</FaqItem>

<FaqItem id="the-analysis-fails-because-addaxai-cannot-write-to-the-folder" q="The analysis fails because AddaxAI cannot write to the folder">

AddaxAI writes a hidden `.addaxai` folder next to your files, so it needs write access there.

- On a Mac, the drive is almost always formatted for Windows (NTFS). Install an NTFS driver, or copy the folder to your own disk. Don't reformat the drive, that erases it.
- On a shared or network folder, ask for write access, or copy the folder somewhere you can write.

</FaqItem>

<FaqItem id="the-app-says-the-previous-run-did-not-finish" q="The app says the previous run did not finish. Where are my results?">

The run was interrupted, so its results never reached the database or a backup. Reconnect the drive if it was external.

The detection progress does survive. Open the folder again, click "Re-run analysis" and choose Continue. Continue is only offered for photos, and only with the same detection settings.

</FaqItem>

<FaqItem id="i-deleted-the-addaxai-files-from-my-folder-but-it-still-says-already-analysed" q="I deleted the AddaxAI files from my folder, but it still says the folder is already analysed">

That's expected: the results live in the database, and the files in your folder are copies.

- Click "Skip analysis" to open the results and save the outputs again.
- Click "Re-run analysis" to start over.
- To forget the run, click "Show recent runs" in Analyse a folder and delete it there.

</FaqItem>

## Getting help

<FaqItem id="something-went-wrong-or-i-found-a-bug" q="Something went wrong, or I found a bug">

Open Help > Export diagnostic report and email the zip to [peter@addaxdatascience.com](mailto:peter@addaxdatascience.com), with what you were doing. See [troubleshooting](./troubleshooting.md).

</FaqItem>

<FaqItem id="how-do-i-cite-addaxai" q="How do I cite AddaxAI?">

Cite the paper: van Lunteren, P. (2023). AddaxAI: A no-code platform to train and deploy custom YOLOv5 object detection models. Journal of Open Source Software, 8(88), 5581. [doi.org/10.21105/joss.05581](https://doi.org/10.21105/joss.05581).

Cite the models you used too. Their citations are in the [model zoo](../reference/model-zoo.mdx).

</FaqItem>
