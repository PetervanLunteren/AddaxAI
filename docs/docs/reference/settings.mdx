# Settings

What each project setting changes, and whether it affects new analyses only or everything at once.

<AppShot name="settings" />

## Models

| Setting | What it does |
|---|---|
| Detection model | Finds animals, people and vehicles. MegaDetector works almost everywhere |
| Classification model | Names the species. Pick one that covers your region |
| Embedding model | Powers similarity search, so you can group animals that look alike |

Changing a model does not relabel what you already analysed. It applies to the next run.

Country and state matter for some species models. They rule out species that do not occur where you work. Set them correctly or you may lose valid species.

## Thresholds

| Setting | Default | Effect |
|---|---|---|
| Counting threshold | 0.2 | What you see and what gets counted. Change it any time, nothing is deleted |
| Classification gate | 0.1 | Which animal boxes get sent to the species model. Applies to new analyses only |

Detections you verified always count, whatever the threshold. See [confidence and verification](../understanding/confidence-and-verification.md).

## Event grouping

**Independence interval**, 1800 seconds (30 minutes) by default.

Photos from one camera taken less than this apart belong to the same event. It is the standard way to avoid counting one animal many times.

Raise it if your cameras fire in long bursts. Lower it if animals pass often and you want them separated.

Changing it regroups every event in the project. Counts you already confirmed are carried over where the same photos end up together again. Where events merge or split, that sign-off cannot follow, so the app warns you first.

## Timezone

Used only to work out sunrise and sunset for the day and night bands on activity charts. It never changes the times shown or stored. See [dates, times and timezones](../understanding/capture-times.md).

## Video

**Frames per second** controls how many frames are pulled from each video for analysis. Higher finds more, and takes longer.

## Advanced

Leave these alone unless you have a reason.

| Setting | What it does |
|---|---|
| Batch size | How many images go through the model at once. Lower it if you run out of memory |
| Image size | Overrides the detector's own image size. Changes both speed and what gets found |
| Augmentation | Runs the detector with extra image variations. Slower, sometimes finds a little more |

## Species selection

You can exclude species a model knows but that do not occur in your area. Excluded species are not applied to your results.

This does not restrict what you can pick by hand. A human correction is a stronger signal than the model, so you can still assign a species you excluded, for a vagrant or an escape.
