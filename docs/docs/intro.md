# AddaxAI

AddaxAI turns raw camera-trap images and videos into clean, verified, ecological data. Point it at a folder, run the AI, check the labels, and get results out. Or build a project to track cameras over time with dashboards, maps, and verification history.

This site is the documentation. Use the sidebar to move around, or the search box at the top to jump straight to a topic.

## Two ways to work

AddaxAI has two modes, and you can start with either.

### Analyse a folder

A one-off run in three steps: setup, labels, save. Run the AI, clean up labels if you want, and get files out: detection tables, a recognition file for Timelapse, species-separated folders, visualised or blurred images. No ecological interpretation, you do your own analysis with the files. A folder run can be turned into a project later.

See [Analyse a folder](./analyse-a-folder/overview.md).

### Build a project

A stored workspace for tracking cameras over time. Confirm species counts, keep verification history, watch dashboards and maps, and export to Camtrap DP. It is additive: keep adding deployments and the analyses update with them.

See [Projects](./projects/overview.md).
