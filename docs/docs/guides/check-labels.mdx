# Check the labels

The AI gives every animal a species, and some will be wrong. This page shows how to find the mistakes fast. Checking is optional. If you report numbers, check at least the species you report on.

## Detections and files

The Labels page has two tabs. They show the same work in two ways.

- Detections has one card per animal: a crop with the species the AI chose. This is the fast way to check labels.
- Files has one card per photo or video, with the boxes drawn on it. Use it to find animals the AI missed, or to fix a file with several animals at once.

A box you verify in Detections counts for its file. A file you verify in Files takes its boxes out of Detections.

To see the files where the AI found nothing, set Empty to "Show only empty" under More filters. Most of them do have a box, scored too low to show. Lower the detection confidence to bring those boxes back.

## Work in groups

Select a group of cards, then verify, relabel or unverify them in one go. Verified cards are hidden, so every group you clear leaves the grid.

The fastest flow: sort per event, press <kbd>E</kbd> to select the event, then <kbd>M</kbd> to give it the most common label. This works best when most events hold one species.

## Keys

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | Verify |
| <kbd>V</kbd> | Accept the selected box and go to the next one |
| <kbd>R</kbd> | Relabel |
| <kbd>X</kbd> | Mark as false detection |
| <kbd>U</kbd> | Mark as unknown |
| <kbd>1</kbd> to <kbd>9</kbd> | Apply a saved label |
| <kbd>M</kbd> | Apply the most common label |
| <kbd>E</kbd> | Select the whole event |
| <kbd>D</kbd> | Draw a box around a missed animal |
| <kbd>B</kbd> | Hide the boxes |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> (<kbd>Cmd</kbd>+<kbd>Z</kbd> on Mac) | Undo |

With no box selected, a key acts on every box in the picture. The keyboard icon in the toolbar lists every key and lets you set the <kbd>1</kbd> to <kbd>9</kbd> labels.

## Photos

Double-click a file to open it. <kbd>Enter</kbd> verifies it and opens the next one. Verifying a file means the boxes you see are all there is. Weak boxes below your threshold are set aside as false detections.

Missed an animal? Press <kbd>D</kbd>, drag a box around it and pick the species. Drag a box or its corners to fix where it sits.

## Videos

The AI follows each animal through a video. In Detections, each animal gets one card. What you do with that card applies to every frame of the animal.

Open a video in Files to see the whole video. Under the video is a timeline with one bar per animal.

- Click a bar to select that animal.
- <kbd>Shift</kbd> with the left or right arrow steps one frame back or forward.
- MaxN next to a species goes to the frame with the most of that species at once.
- <kbd>P</kbd> plays the video.

With an animal selected, <kbd>V</kbd>, <kbd>X</kbd> and <kbd>R</kbd> act on that animal. With nothing selected, they act on the animals in the frame you see. <kbd>Enter</kbd> verifies those and moves on to the next animal you have not checked, so you can walk through a video with Enter.

"Verify the whole clip" verifies every animal in the video, also the ones you did not look at. Use it only when you are sure.

To add an animal the AI missed, draw it on the frame you count on, usually the MaxN frame. Or type the number on the Counts page.

### When the AI switches animals

Sometimes the AI follows one animal and then jumps to another, for example when two fish cross. The card can't show that, because it is one picture.

Click Frames on a video card to see every frame of that animal. If some frames show a different animal, select those frames and relabel them. <kbd>Esc</kbd> takes you back.

Some frames are blurry or half hidden. That is normal: the AI keeps weak boxes to follow an animal through cover. The card's species is a vote over all frames, so one bad frame does not change it. See [how labels get cleaned up](../understanding/label-cleanup.md).

## Same in folder runs and projects

It is the same grid in both: step 2 of a folder run, and the Labels page of a project. To change thresholds, the species selection or the event interval, use Refine results in a folder run, or the Settings page in a project.

## Sort look-alikes together

The grid opens sorted per event, so each visit stays together. Sort by similarity to put look-alike animals together across the whole project. You get a block of opossums, then a block of deer, and the odd one stands out. In the screenshot at the top, two cards are not opossums.

Both need the embedding model. Without it, the grid sorts by date.

## Filters

Filter by label, verified status, site or date. When you sort by similarity, do not filter to one species. If every card says wolf, a wrong one does not stand out. Filter to a broader group instead, for example all canids. A wolf labelled as a coyote then sits among the real coyotes.

## Suggestions

The app can point out likely mistakes. It compares each animal with its closest look-alikes. If those mostly carry another label, you get a suggestion. For example, a "canis" whose look-alikes are all "domestic dog".

Click Review when the toolbar shows a suggestions badge. Accept relabels and verifies the whole group. Dismiss hides it. Suggestions look at the newest 100,000 detections. In a larger project, set a date range or pick sites to check the rest.

## Your corrections win

Reprocessing and threshold changes never touch what you corrected. Re-running the AI does, because it starts from scratch. See [confidence and verification](../understanding/confidence-and-verification.md).

## Labels are not counts

Checking labels tells you which species, not how many. Check the labels first, then [confirm the counts](./confirm-counts.mdx).
