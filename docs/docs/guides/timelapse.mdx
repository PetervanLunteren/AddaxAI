# Use results in Timelapse

Timelapse is a separate program for reviewing camera trap photos. It runs on Windows only, and you can get it from [its download page](https://timelapse.ucalgary.ca/download/). AddaxAI writes a recognition file that Timelapse reads, so you can go through the AI results inside Timelapse.

Only a folder run makes this file. Timelapse needs one fixed folder, with the recognition file sitting next to the photos. A folder run is exactly that. A project can hold many folders in different places that move over time, so it does not fit.

## Steps

1. **Start AddaxAI on your folder.** Two ways:

   - **From Timelapse:** choose Recognitions > AddaxAI Image Recognizer > Run AddaxAI recognizer on a folder. AddaxAI opens "Analyse a folder" with that folder already filled in.

     ![The AddaxAI recognizer in Timelapse's Recognitions menu](/img/timelapse-recognitions-menu.webp)

   - **From AddaxAI:** start a folder analysis on the folder yourself.

     ![Start folder analysis from the AddaxAI home screen](/img/home-analyse-a-folder.webp)

2. **Run the folder analysis as normal.** Nothing here is Timelapse-specific. See [analyse a folder](./analyse-a-folder.mdx).

3. **Save the recognition file.** In the save step, turn on JSON, the recognition file for Timelapse. AddaxAI writes `addaxai-recognitions.json` next to your photos. Do not move it: Timelapse finds your photos through paths relative to where the file sits.

   ![The JSON recognition file option in the save step](/img/save-recognition-file.webp)

4. **Import into Timelapse.** Choose Recognitions > Import image recognition data for this image set, then pick the file.

For more detail on the Timelapse side, see their [image recognition guide](https://timelapse.ucalgary.ca/imagerecognition/).
