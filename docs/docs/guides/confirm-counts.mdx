# Confirm the counts

The AI counted how many animals of each species it saw in each event. On the Counts page you check those numbers and confirm them. Checking is optional.

The count is the most animals of a species in any single photo of the event, so one deer photographed 40 times is one deer. See [detections, events and observations](../understanding/detections-events-observations.mdx).

## Go through the events

Each card is one event. It opens on the photo or frame with the most animals, so you can judge the species and the number in one look. The strip below holds the rest of the event.

- Check the species and counts in the panel on the right.
- Change a count, or add a species the AI missed.
- Press <kbd>Enter</kbd> to confirm and go to the next event.

Your numbers replace the AI's everywhere: in the charts, the rates and the exports. Events you don't confirm still count, with the AI's number.

For a video, each species row says when its count was reached and when the species first arrived. Show takes you to that frame, with the same timeline under it as on the Labels page.

## Sex, age and behaviour

Under each species you can set sex, age and behaviour. It's optional, and the AI never fills it in. To record 4 males and 2 females, click "Split into two rows" and set each row's count and sex.

Press <kbd>C</kbd> to copy the rows of the last event you confirmed. Below the list is a note field for anything else.

## Keys

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | Confirm and go to the next event |
| <kbd>Space</kbd> | Play through the photos of the event |
| <kbd>Shift</kbd>+<kbd>←</kbd> or <kbd>→</kbd> | Previous or next photo or frame |
| <kbd>↑</kbd> or <kbd>↓</kbd> | Pick a species |
| <kbd>0</kbd> to <kbd>9</kbd> | Set its count |
| <kbd>+</kbd> or <kbd>-</kbd> | Count one up or down |
| <kbd>N</kbd> | Add a species |
| <kbd>A</kbd>, <kbd>S</kbd>, <kbd>J</kbd> | Age: adult, subadult, juvenile |
| <kbd>M</kbd>, <kbd>F</kbd> | Sex: male, female |
| <kbd>C</kbd> | Copy the rows of the last confirmed event |

Press an age or sex key again to set it back to unknown.

## Same in folder runs and projects

It is the same gallery in both: step 3 of a folder run, and the Counts page of a project. To change the independence interval, use Refine results on the Labels step in a folder run, or the Settings page in a project.

## Events where nothing happened

Events where the AI found nothing are hidden. To see them, open More and set Empty to "Show only empty". To see every empty photo, also inside events with animals, use the Files tab on the [Labels page](./check-labels.mdx) with the same filter.
