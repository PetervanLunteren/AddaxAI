# What AddaxAI does

AddaxAI finds the animals in your camera trap photos and videos, and tells you which species they are. It runs on your own computer. Your files stay on your machine.

You give it a folder. It does three things:

  { icon: stepIcons.find, verb: "Find", body: "A detection model draws a box around each animal, person and vehicle." },
  { icon: stepIcons.name, verb: "Name", body: "A classification model says which species is in each box." },
  { icon: stepIcons.check, verb: "Check", body: "You review what the AI suggested and correct anything that is wrong." },

These three steps are the same whichever way you work. What happens next is where the two modes differ.

## Two ways to work

**Analyse a folder.** Point at one folder and get the results straight out: tables, sorted folders, or a file for another program such as Timelapse. Good for a one-off batch that you will analyse elsewhere.

**Build a project.** Keep adding folders over time. Results from every camera add up into counts, rates, maps and charts, all inside AddaxAI.

The AI does the same work either way, so the detections and species are identical. What differs is how much interpreting AddaxAI does afterwards. And nothing is locked in: a folder run can become a project later, without losing anything.

## What it does not do

- It does not replace your own analysis. The built-in charts and rates cover the usual camera trap questions, and for some projects that might be enough. For anything more specific, like occupancy or density models, export the data and run it in R.
- It does not upload anything. There is no account and no cloud.
- It is not always right. The species and the counts are suggestions. Check the ones that matter to your result, and accept the rest. See [confidence and verification](../understanding/confidence-and-verification.md).
